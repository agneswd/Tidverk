# Repository agent instructions

## Git naming

- Use Conventional Commits: `type(scope): imperative summary`.
- Name branches `type/short-kebab-description` using a Conventional Commit type such as `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, `ci`, `build`, or `perf`.
- Format pull request titles as Conventional Commits.
- Keep agent, model, tool, vendor, and personal names out of branch names, commit messages, and pull request titles unless the name is part of the product change.
