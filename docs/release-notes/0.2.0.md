# Tidverk 0.2.0

Tidverk now ships as a normal Windows installer and a Linux AppImage.

- Added automatic update checks through GitHub Releases
- Added background downloads, sidebar progress, and restart controls
- Added a one-click Windows Setup executable
- Added a portable Linux AppImage and optional user-level installer bundle
- Published Tidverk as open-source software under the MIT License

Existing 0.1.0 installations need one manual installation of 0.2.0. Tidverk keeps the existing local database and reports.
